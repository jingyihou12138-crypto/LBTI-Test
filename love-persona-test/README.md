# 人设测试网页

纯前端单页应用：输入出生日期/时间/地点 + MBTI，浏览器本地算出日/月/金/火/上升落座，按《恋爱人设映射规则（定稿）.md》映射出本命人设（第一句 + 详细介绍）、置信度和 CP 配对（本人视角）。隐藏人设仅保留在数据层（`computeResult` 的 `hidden` 字段），页面不展示。

## 使用方式

双击 `index.html` 即可（所有依赖本地引入，无需联网、无需后端）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构与样式（移动端友好） |
| `app.js` | 表单交互（年/月/日、时/分下拉，省市二级联动）与结果渲染 |
| `logic.js` | 核心逻辑：时区换算、天文计算（回归黄道落座 + 上升公式）、四维画像、贴合打分、人设/MBTI/CP 硬编码数据 |
| `cities.js` | 出生地点数据：34 个省级行政区 + 全部地级行政区（约 340 个，含地州盟）+ 海外/其他分组，带经纬度与时区 |
| `astronomy.browser.min.js` | astronomy-engine v2.1.19 浏览器版（npm registry 下载，本地引用） |
| `脚本/verify_astro.mjs` | node 对拍：JS 天文计算 vs Python 权威盘（chart_astrology.py），含 3 个端到端案例 |
| `脚本/verify_page.mjs` | 页面装配冒烟测试：脚本顺序、DOM id、省市数据完整性、数据集坐标回归 |
