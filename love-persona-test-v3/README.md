# 恋爱人设测试 · v1 / v3 规则对比试玩页

带 **v1 / v3 规则版本切换开关**的试玩版，用来在决定是否采用 v3 之前多试几个人、直接对比同一份输入在两版规则下的差异。

- **默认版本**：v3（候选版）
- **线上正式版仍是纯 v1**，地址 [`../love-persona-test/`](../love-persona-test/)，本页不影响它

## 怎么用

1. 顶部吸顶的开关切 `v1 定稿` / `v3 候选`，**切换后同一份输入立即重算**，不用重新填表。
2. 结果页顶部会给出两版对比横幅：
   - 结果不同 → 橙色横幅写出 `v1：X → v3：Y`
   - 结果相同 → 绿色横幅（若只是置信度档位不同，会解释原因）
3. v3 触发**批外翻盘**时，会多出一条深紫色横幅（这个机制全人群触发率只有 2.66%）。
4. 结果卡上的徽章标出当前版本、置信度、以及**判定路径**（首选当选 / 次选上位 / ⚡ 批外翻盘）。
5. 最底下「🔧 后台调试」折叠区里是 **v1 / v3 双列得分榜**，带层级标记（首 / 次 / 外），并解释这次两版为什么不同。

表单交互（省市二级联动、下拉选日期时间、「我不知道出生时间」开关、CP 单视角、人设两段式文案）与正式版完全一致。

## v3 相对 v1 改了什么

设计立场是 **MBTI 主锚、星盘批内区分**：

- MBTI 首选 **+4** / 次选 **+2** 与 v1 完全一致，一分未动（首选当选率 97.3%）
- 修 5 处人设四维值（ROBOT / SOLO / PLAY / DRUM / CHOCO）——v1 里 ROBOT 与 CUPP 四维值一字不差，导致 ROBOT 占比恒为 0
- 补 5 处候选批首选位（ESFJ+DOGG、ENTJ+GUID、INTP+2G、ISTP+SOLO、ISTJ+CHOCO）——v1 里 SOLO / 2G 从来不是任何 MBTI 的首选，占比数学上恒为 0；ESFJ / ISTJ / ENTJ 三型的结果与星盘完全无关
- 把批外翻盘门槛从「首选分的副产品」拆成独立参数 **1.5**——v1 那条「高出 4 分可翻盘」是死条款（4 > 同盘贴合分极差 2.758，全空间穷举 0 次触发）
- 置信度阈值按 v3 分布重新校准为 **4.2 / 3.6**（v1 的 3.8 / 2.5 让 69.7% 的人都是「强共鸣」，档位失去区分度）

结果：20 个人设全部可达（v1 有 3 个恒为 0），头部 MAMA 从 23.69% 降到 19.69%，翻盘率 0% → 2.66%。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构与样式（含版本开关、对比横幅、双列得分榜） |
| `app.js` | 表单交互 + 双版本渲染与切换 |
| `logic.js` | **v1 逻辑，与正式版逐字一致**（同时提供天文排盘、人设文案、CP 数据） |
| `logic-v3.js` | v3 打分逻辑（只重写打分/映射，天文排盘复用 v1） |
| `demo-cases.js` | 快捷试玩案例，页面与验证脚本共用的唯一来源 |
| `cities.js` | 出生地点数据（省市两级 + 海外） |
| `astronomy.browser.min.js` | astronomy-engine v2.1.19（本地引入，双击 index.html 可离线用） |
| `脚本/verify_v3_render.mjs` | 渲染验证：版本切换、横幅文案与出现条件、双列得分榜、试玩案例结果 |

`node 脚本/verify_v3_render.mjs` 可直接跑（零依赖）。打分层的「浏览器 ↔ node 对拍」脚本依赖主工作区的 node 版 v3 引擎，未随页面部署。

> 娱乐向自我探索，结果不构成任何承诺。准确率未经验证。
